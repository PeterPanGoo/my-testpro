# Prism：原生空间感知多模态框架规格 v0.1

## 0. 文档定位

Prism 是一个可证伪的研究假设，不是已被实验确认的模型。本文给出模块边界、张量契约、目标函数、训练路线、消融矩阵和通过/失败条件；`src/prism` 则是验证接口与计算图的最小参考实现。

当前仓库没有所述 18 篇论文的完整书目信息，因此本文只把用户给出的论文简称作为设计溯源标签，不补造作者、年份或实验结论。正式研究计划应在立项前补齐引用并复核原文。

## 1. 核心假设与可证伪条件

**假设 H1：** 把视觉压成单一 token 序列并主要交给语言骨干，会系统性损害度量几何、时序一致性及视觉证据优先性。

**干预 I：** 在相同数据、训练 FLOPs 和参数量预算下，用三通道等长视觉潜空间、`what`/`where` 双通路和非自回归空间头替代单通路自回归基线。

**支持 H1 的最低证据：** Prism 在至少两个独立空间能力族（度量几何、长时跟踪、反事实 grounding）上显著优于预算匹配基线，且提升不能由更多参数或额外监督解释。

**否证条件：** 完整模型相对预算匹配基线没有稳定提升；移除几何通路后不退化；或提升完全来自显式深度监督而非架构。任一情况都要求缩小或放弃 H1，而不是继续刷单一综合分。

## 2. 系统边界

### 2.1 输入

- RGB 图像：`I ∈ R[B, 3, H, W]`。
- 视频：`V ∈ R[B, T, 3, H, W]`；v0.1 参考代码先逐帧编码，正式实现加入时空坐标与记忆。
- 可选几何监督/先验：`G ∈ R[B, Cg, H, W]`，推荐通道为度量深度、法向量和置信度。通道语义由数据适配器声明。
- 可选文本：由外部 tokenizer/LLM 适配器处理；不属于 UVE 的强制输入。

要求 `H`、`W` 能被 patch 大小 `P` 整除。`N = H/P × W/P`。

### 2.2 输出

统一空间头输出固定槽集合 `Y ∈ R[B, Q, Dy]`。具体任务通过任务适配器定义槽语义，例如：

| 任务 | 一个槽的建议字段 |
|---|---|
| 2D grounding | `cx, cy, w, h, objectness, class embedding` |
| 深度 | patch/像素深度值与置信度 |
| 3D | `x, y, z, scale, rotation, occupancy` |
| 轨迹 | 对象/点在时间轴上的坐标与可见性 |
| 分割 | 掩码 latent，交给并行 mask decoder |

不同拓扑不应强塞进同一个 `Dy`；生产实现使用任务注册表和独立 codec。参考代码只实现抽象连续槽。

## 3. 总体架构

```text
RGB ─┬─ semantic encoder ─┐
     ├─ appearance codec ─┼─ concat(channel) ─ fusion ─ semantic-flow reorder
     └─ geometry model ───┘                              │
                                                        ├─ what pathway ─┐
coordinates ────────────────────────────────────────────┴─ where pathway ┤
                                                            ↕ cross-path │
                                                                         └─ context
                                                                              │
noise slots ───────────────── conditional flow matching ──────────────────────┘
```

三种 token 在 patch 轴完全对齐，只沿通道轴拼接，因此序列长度仍为 `N`：

`Zraw = concat(Zsem, Zapp, Zgeo) ∈ R[B, N, Ds+Da+Dg]`

`Z0 = Linear(LN(Zraw)) ∈ R[B, N, D]`

## 4. 模块规格

### 4.1 统一视觉编码器 UVE

1. **语义通道**：目标是类别、部件和跨图对齐。正式实现可接 ViT/DINO 类编码器。
2. **外观通道**：目标是纹理、颜色和可逆细节。正式实现可接 VAE encoder，训练时保留重建约束。
3. **几何通道**：目标是深度、法向、边界、置信度和相机信息。允许外部几何输入；缺失时由几何估计器产生。

三个编码器必须输出同一 patch 网格。禁止在融合前将几何压成自然语言或离散坐标字符串。

参考实现用三组轻量卷积 patch projection 固定接口；它不是预训练 ViT/VAE/深度网络的性能替代品。

### 4.2 语义流重排

学习标量显著性 `s_i = MLP(z_i)`，按降序得到置换 `π`，并对 token、原始通道与坐标执行同一置换。所有需要回到栅格的头必须保存 `π⁻¹`。

离散排序对排序索引不可导，但被选 token 的值仍可导。正式实验必须与以下方案对照：无重排、硬排序、可微 Sinkhorn 重排、因果查询 cross-attention。否则不能把提升归因给“因果流”。

### 4.3 `what` 通路

输入/输出均为 `R[B,N,D]`。职责是识别、关系语义、语言对齐和符号推理。参考实现是 pre-norm Transformer encoder；接现有 LLM 时通过投影器或 cross-attention adapter 对齐维度，并明确冻结策略。

### 4.4 `where/how` 通路

每个 token 携带连续坐标 `p_i=(x_i,y_i[,t_i,z_i])`。注意力分数为：

`a_ij = q_i k_jᵀ / sqrt(dh) + b_h([p_i-p_j, ||p_i-p_j||])`

其中 `b_h` 是每个 head 的相对几何偏置。它保证平移后的相对坐标不变，但参考实现**不宣称严格旋转或 SE(3) 等变**。严格等变版本应替换成经过验证的 E(2)/SE(3) 模块，并单独消融。

### 4.5 跨通路交换

每一交换层执行双向 cross-attention：

- `what ← CrossAttn(Q=what, K/V=where)`
- `where ← CrossAttn(Q=where, K/V=what)`

两次注意力从同一层输入并行计算，避免更新顺序造成隐式主从关系。交换后拼接并线性融合为条件上下文 `C ∈ R[B,N,D]`。

### 4.6 条件流匹配空间头

令真实空间结构为 `x1`，高斯噪声为 `x0`，采样 `t ~ U(0,1)`：

`xt = (1-t)x0 + t x1`

目标速度：

`u*(xt,t) = x1 - x0`

网络 `vθ(xt,t,C)` 同时预测全部 `Q` 个空间槽。推理从噪声出发，用 Euler/Heun/ODE solver 对 `dx/dt=vθ` 积分；没有左到右的槽生成顺序。

固定槽会产生集合匹配问题。检测/轨迹任务在构造 `x1` 前应使用 Hungarian matching 或确定性 canonicalization；掩码和稠密深度则使用固定空间索引。参考实现假设适配器已经完成对齐。

## 5. 目标函数

总损失：

`L = λflow Lflow + λapr Lapr + λgeo Lgeo + Σk λk Ltask,k`

### 5.1 Focal flow regression

`e = |vθ-u*|`

`w(e) = (1-exp(-e/σ))^γ`

`Lflow = mean(stopgrad(w(e)) · SmoothL1(vθ,u*))`

权重对误差停止梯度，降低网络通过操控权重函数取巧的空间。必须报告普通 MSE/SmoothL1 对照，确认 focal 没有牺牲小误差区域的度量精度。

### 5.2 APR（辅助预测重建）

随机遮盖比例 `r` 的融合 token，以 mask token 替换，再重建融合前的三通道 `Zraw`：

`Lapr = SmoothL1(Decoder(mask(Z0)), Zraw)`（仅在被遮位置计算）

正式版建议按通道报告重建误差，并采用独立 decoder，避免单一高方差通道支配损失。

### 5.3 几何监督

有真值时对几何估计器施加 focal SmoothL1。深度需同时评估绝对尺度与 scale-invariant 指标；法向使用余弦损失；无效像素必须通过 mask 排除。参考实现只给出通用回归项。

## 6. 训练协议

### S0：预算匹配基线

- 固定数据切分、图像分辨率、总训练 token/FLOPs、参数量区间和推理预算。
- 至少包含：单通路视觉 token→语言骨干、自回归坐标输出、相同视觉编码器+普通并行回归头。
- 在训练前锁定主指标与失败条件。

### S1：三通道表征

- 预训练/接入语义、外观、几何编码器。
- 验证三通道网格对齐、反置换正确性和几何尺度标定。
- 只训练融合器与 APR，检查每通道是否能被恢复；不能只看总重建误差。

### S2：双通路

- 冻结 `what` 主干，训练 `where`、跨通路层和任务头。
- 关键门槛：在不损伤语义基线超过预设容忍度的情况下，空间任务显著提升。
- 消融 `where`、坐标、相对几何偏置和跨通路方向。

### S3：联合训练与流头

- 先独立训练 flow head，再小学习率联合解冻，避免未成形的空间梯度破坏语义表征。
- 混合任务按有效 token 或不确定性归一化损失，记录每项梯度范数。
- 加入真实、合成和人机协同数据；每种来源分别报告性能，防止数据泄漏掩盖架构效果。

### S4：规模化

- 只在 S2/S3 通过门槛后扩规模。
- 公开配置、数据版本、随机种子、训练曲线、失败案例和计算成本。

## 7. 评测与统计

| 能力族 | 主指标 | 必须的对照/切片 |
|---|---|---|
| 度量深度 | AbsRel、RMSE、尺度误差 | 室内/室外、近/远、已知/未知相机 |
| 3D 重建 | Chamfer、F-score、尺度/姿态误差 | 稀疏纹理、反光、遮挡、OOD 类别 |
| 长时跟踪 | survival、位置误差、遮挡后恢复 | 轨迹长度、速度、遮挡时长 |
| 反事实 grounding | 视觉证据胜出率、定位误差 | 先验冲突强度、对象频率 |
| 图文逻辑鸿沟 | `score_text-score_image` 与置信区间 | 同题同语义、控制 OCR 难度 |
| 语义保持 | 分类/VQA/检索基线指标 | 防止空间提升以语义退化换取 |

每项至少运行 3 个随机种子，报告均值、标准差、bootstrap 95% CI 和配对效应量。主结论不使用只在单数据集成立的 cherry-pick 结果。

“WAIS 式 AIQ”只能作为多维诊断剖面，不能直接等同人类 IQ 或作为唯一主指标；必须公开题目构造、常模和模型可见信息。

## 9. 数据飞轮与防泄漏

1. 模型在未标注池上提出高不确定性样本与候选几何。
2. 人或可靠工具修正；保留原始候选、修订和审计记录。
3. 按场景/来源/时间分组去重后进入下一训练轮。
4. 固定测试集永不回流；合成模板和资产也按族隔离。
5. 每轮报告新增数据带来的增益与架构本身增益，禁止混为一项。

## 10. 工程接口和扩展点

- `UnifiedVisualEncoder.forward(images, geometry?) -> VisualTokens`
- `PrismModel.encode(...) -> {visual, what, where, context}`
- `PrismModel.forward(..., spatial_targets?) -> outputs + named losses`
- `PrismModel.sample(..., steps, noise?) -> [B,Q,Dy]`

建议后续新增：

- `BackboneAdapter`：注册真实 ViT、VAE、深度网络和 LLM。
- `TaskCodec`：在原始标注与连续槽间编码/解码并处理集合匹配。
- `VideoUVE`：加入 `(x,y,t)` 坐标、显式 memory 和遮挡状态。
- `Evaluator`：锁定数据哈希、指标版本、置信区间与反事实切片。
- 分布式训练、混合精度、checkpoint、EMA 和配置解析层。

## 11. 参考实现与论文设想的差距

| 设想 | v0.1 参考实现 | 达到研究级所需工作 |
|---|---|---|
| 预训练三编码器 | 轻量 Conv patch encoder | 接权重、对齐分辨率和归一化 |
| 语言 `what` 骨干 | 小型 Transformer | LLM adapter、文本 token、冻结/LoRA 策略 |
| 几何等变 | 2D 相对位移偏置 | 严格 E(2)/SE(3) 层与相机坐标建模 |
| 因果流重排 | 学习显著性硬排序 | 可微重排和因果查询消融 |
| 多任务空间输出 | 抽象固定连续槽 | 每任务 codec、matching、有效性 mask |
| 流求解 | Euler | Heun/自适应 ODE、CFG/约束投影 |
| 视频一致性 | 尚未实现 | 时空 token、记忆、轨迹身份和遮挡 |

这张差距表也是验收边界：代码能验证模块连通、形状和梯度，不能证明 Prism 的科学论点成立。
